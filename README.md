# 靜謐藏書閣（Private Library Archive）

個人閱讀書籍紀錄檢索系統是一套以古典圖書館與原木書架為視覺風格的前端應用。本專案將 Obsidian 雙向筆記庫中的閱讀清單自動轉化為具備多維檢索、物理質感書架與系列專題脈絡的可視化閱讀平台，並支援透過自動化流程持續部署至 GitHub Pages。

## 一、 系統架構與模組劃分

本專案採用職責分離的模組化架構，將單體 HTML 拆分為結構層、樣式層、資料層與邏輯層，確保程式碼具備良好的可讀性、維護性與低上下文消耗特性：

1. **結構層（DOM Skeleton）**：
   * 檔案：`index.html`
   * 職責：負責頁面語意化標籤骨架、資安標頭、各視角容器與彈窗模態框配置。不包含大量內聯樣式或邏輯腳本。

2. **樣式層（Style & Texture）**：
   * 檔案：`css/style.css`
   * 職責：封裝古典圖書館主題樣式，包含深色胡桃木質底色、羊皮紙質感、黃銅銘牌、書脊物理厚度與高度陰影、響應式捲軸與互動動畫。

3. **資料層（Data Storage）**：
   * 檔案：`js/books-data.js`
   * 職責：儲存由同步腳本自 Markdown 筆記解析出的完整書籍陣列（`booksDatabase`）與成套系列套書陣列（`seriesDatabase`）。

4. **邏輯層（Application Logic）**：
   * 檔案：`js/app.js`
   * 職責：負責前端生命週期管理、DOM 渲染、即時多維條件篩選演算法、隨機薦讀邏輯、書目引文生成、資安過濾（XSS 防禦與 URL 消毒）及本機收藏狀態存取。

## 二、 核心功能與視覺設計

### 1. 多重視角切換
* **典藏索書卡檢索台（Card Catalog）**：
  模擬圖書館傳統抽屜式索引卡片。每張卡片標示索書號、學科標籤、ISBN、借閱流通狀態、星級評分、閱讀日期與重點筆記。點擊卡片可開啟詳細典藏資訊彈窗。
* **典藏原木書架（Realistic Bookshelf）**：
  提供擬真排架視覺。同類型書籍採用統一色彩識別；同系列套書維持齊平高度；漫畫類別降低書身高度；繪本類別縮減書脊厚度；書脊直式排印燙金書名與索書號，依物理厚度流暢排列於原木隔板。
* **成套系列叢書（Series Collections）**：
  針對大型系列作品（例如：艾西莫夫基地系列、沙丘系列、進擊的巨人、三體等）獨立專題展示。提供首冊封面、閱讀進度、冊數統計與系列傳承分析。
* **館藏數據盤點牌匾（Library Analytics）**：
  顯示總藏書量、已完讀冊數、完讀率百分比、現正借閱中冊數與十大涵蓋學門統計。

### 2. 多維度動態檢索
* 支援依據「閱讀年度」（全部年度、2026、2025、2024 等）進行篩選。
* 支援依據「流通狀態」（全部狀態、已完讀歸架、正在借閱中）進行篩選。
* 支援依據「學科分類」（科幻奇幻、心理學、漫畫、歷史文化、自然科學等）進行多重篩選。
* 支援全域關鍵字即時檢索，涵蓋書名、作者、譯者、出版社、ISBN、標籤與閱讀筆記。
* 提供「館員隨機薦讀」功能，隨機推薦符合目前篩選條件的典藏書目。
* 提供「複製書目報表」功能，將檢索結果格式化為清單文字以供匯出。

### 3. 書目詳細資訊與標準引文
* 於詳情彈窗內提供博客來、誠品或官方商品資訊之安全連結。
* 提供一鍵複製 APA 與 MLA 格式標準學術引文功能。
* 支援「加入珍藏」標記功能，狀態安全保存於瀏覽器 LocalStorage。

## 三、 安全防護機制

為確保前端在靜態部署環境下的穩健性，本系統實施以下資安防禦規範：

1. **內容安全政策（Content Security Policy, CSP）**：
   * 限制腳本來源為 `'self'` 及特定信任之 CDN（如 Google Fonts、Tailwind 官方 CDN）。
   * 禁止未經授權的跨域連線與外站物件嵌入（`object-src 'none'`）。
2. **防點擊劫持（Anti-Clickjacking / Frame Busting）**：
   * 透過內聯防禦腳本強制檢驗 `self === top`。若偵測到頁面被惡意 iframe 嵌套，立即中止渲染並轉址頂層視窗。
3. **嚴格的 XSS 轉義防禦**：
   * 所有動態渲染之文字資料（書名、作者、筆記、引文）在插入 DOM 前，一律通過專用 `escapeHtml` 函式將敏感字元（`&`, `<`, `>`, `"`, `'`）完全轉換為 HTML 實體。
4. **URL 協議白名單消毒**：
   * 所有封面圖片連結（`coverUrl`）與外部資訊連結（`booksUrl`）均透過 `sanitizeUrl` 驗證，僅允許 `http:`、`https:` 或以安全 Data URI 格式載入，徹底防堵 `javascript:` 等偽協議攻擊。
5. **本地儲存格式校驗**：
   * 讀取 LocalStorage 之收藏書籍清單時，嚴格檢驗其格式必須為正規化安全 ID（僅允許英數字元、底線與連字號），剔除任何潛在的腳本注入字串。

## 四、 檔案目錄結構

專案資料夾維持自包含架構，完全收納於 `reading-log/` 目錄內：

```text
reading-log/
├── .gitignore              # Git 版本控制忽略設定檔
├── README.md               # 專案完整中文說明文件
├── favicon.svg             # 典藏書本書標向量圖示
├── favicon.ico             # 點陣相容圖示
├── index.html              # 應用程式純語意化 HTML 骨架
├── sync.py                 # Markdown 解析與自動化同步發布腳本
├── css/
│   └── style.css           # 擬真質感、書脊排架與古典排版樣式
└── js/
    ├── books-data.js       # 書籍與系列套書全域資料庫
    └── app.js              # 前端檢索、渲染與防禦核心邏輯
```

## 五、 環境需求與維護流程

### 1. 執行環境需求
* **Python**：Python 3.8 或更新版本。
* **版本控制**：Git 2.0 或更新版本。
* **瀏覽器**：支援現代 ES6 標準之瀏覽器（Chrome、Safari、Firefox、Edge）。

### 2. 日常維護步驟
1. 於 Obsidian 筆記庫編輯上層目錄的 `Reading log.md`，新增或修改閱讀記錄、書籍分類或系列專題表格。
2. 開啟終端機並切換至 `reading-log` 資料夾，執行自動同步腳本：
   ```bash
   python3 sync.py
   ```
3. 腳本將自動完成下列動作：
   * 解析 `Reading log.md` 中全部年份的閱讀清單。
   * 萃取各書之分類、系列歸屬、封面圖片與外部連結。
   * 更新 `js/books-data.js` 資料庫。
   * 更新 `index.html` 內的預載靜態計數指標。
   * 提交 Git Commit 並推播更新至遠端 GitHub 儲存庫。

### 3. 本機離線檢視
* 本專案資料模組採用全域變數機制載入，不受瀏覽器針對本地檔案（`file://`）所實施的跨來源資源共用（CORS）限制。
* 直接雙擊 `reading-log/index.html` 即可於本機離線開啟，各項篩選、書架與卡片功能均能正常運作。

## 六、 自動化同步機制（sync.py）

`sync.py` 負責連接 Obsidian 筆記與 Web 前端展示層，其核心執行邏輯如下：

1. **表格語法解析**：
   * 透過正規表示式循序讀取 `Reading log.md` 中的分類統計表、系列專題統計表以及年度書目明細表。
   * 自動識別閱讀狀態符號（例如：標註「閱讀中」者歸入在讀清單，其餘歸入完讀清單）。
2. **多維關聯對應**：
   * 自動將書目關聯至所屬的十大系列（如基地系列、沙丘系列），並對齊所屬的學科門類與索書號。
   * 保留既有封面連結與外部詳細頁面網址，若無外部連結則維持內部錨點關聯。
3. **無損寫入與發布**：
   * 獨立輸出至 `js/books-data.js`，避免大區塊正規表達式修改 HTML 檔案所帶來的結構損毀風險。
   * 調用本機 Git 工具自動比對檔案差異，若有變更則自動建立版本標籤並推送至遠端 `origin/main` 分支。
